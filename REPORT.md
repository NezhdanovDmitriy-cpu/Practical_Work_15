# Отчёт по практическому занятию № 15

**Вариант:** 11  
**Тема:** Составление программ для работы с базами данных в IDE PyCharm Community.  
**Количество часов:** 6

## Цель работы

Закрепить навыки разработки приложений на Python для создания, заполнения, поиска, изменения и удаления записей однотабличной базы данных.

## Постановка задачи

Разработать приложение «Командировочные расходы» с таблицей «Статьи расходов», содержащей № приказа, фамилию, место командировки, оплату, аванс, вид расходов, сумму расходов. Обеспечить ввод не менее 10 позиций и по три SQL-запроса с условием для поиска, изменения и удаления.

## Ход работы

1. Выбрана SQLite — встроенная реляционная СУБД, доступная через модуль Python `sqlite3`.
2. Создана одна таблица `expense_items` с семью полями; № приказа является первичным ключом.
3. Реализовано начальное заполнение 10 учебными записями и ручное добавление записей.
4. Реализованы три варианта поиска (`SELECT ... WHERE`): фамилия, место командировки, порог суммы расходов.
5. Реализованы три варианта редактирования (`UPDATE ... WHERE`): место, аванс, сумма расходов.
6. Реализованы три варианта удаления (`DELETE ... WHERE`): номер приказа, фамилия, вид расходов. Перед удалением программа показывает подходящие записи и запрашивает подтверждение.
7. Добавлена обработка ошибок ввода, ограничений таблицы и ошибок SQLite. Все пользовательские параметры передаются через `?`, без формирования SQL из введённого текста.

## Проверка

Для проверки в PyCharm запустить `main.py` и выполнить: показать 10 записей; найти записи по фамилии, месту и сумме; добавить запись; изменить место, аванс и сумму расходов; удалить запись по номеру приказа и проверить изменение количества записей. Проверить все варианты поиска, редактирования и удаления.

## Вывод

Разработано консольное приложение Python с однотабличной базой данных SQLite. Предусмотрены ввод, поиск, изменение и удаление записей, включая девять условных SQL-запросов и обработку ошибок. Программа соответствует структуре данных варианта 11.
