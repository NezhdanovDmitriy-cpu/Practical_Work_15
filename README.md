# Практическое занятие № 15 — Вариант 11

**Тема:** Работа с однотабличной базой данных в Python / PyCharm Community.

**Приложение:** «КОМАНДИРОВОЧНЫЕ РАСХОДЫ».

## Запуск

1. Открыть папку проекта в PyCharm Community.
2. Запустить `main.py` с помощью Python 3.
3. При первом запуске программа создаст `travel_expenses.db` (SQLite) и добавит 10 учебных записей.
4. Управлять данными через меню в консоли.

Дополнительные библиотеки не нужны: `sqlite3` входит в стандартную библиотеку Python.

## Структура таблицы

`expense_items`: `order_number` (№ приказа, первичный ключ), `surname` (фамилия), `destination` (место командировки), `payment` (оплата), `advance` (аванс), `expense_type` (вид расходов), `expense_amount` (сумма расходов).

## Функции

- Вывод всех записей и добавление новых.
- Три условных `SELECT`: по фамилии, месту командировки и сумме расходов.
- Три условных `UPDATE`: изменение места, аванса и суммы расходов по № приказа.
- Три условных `DELETE`: по № приказа, фамилии и виду расходов.
- Обработка некорректного ввода, защита параметризованными SQL-запросами, подтверждение удаления.

**Примечание:** В базе учебные, вымышленные данные. Чтобы начать с исходных десяти записей, закройте программу и удалите локальный файл `travel_expenses.db` — он создастся заново при запуске.
